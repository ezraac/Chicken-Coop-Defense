# Chicken Coop Defense
This is a fun little project I hope to complete this summer 2026-2027. I will use this to build a proper working game with documentation of my programming journey and following code patterns to create clean, modular code for my game.

# Tools
The project will be built in [Luau](https://github.com/luau-lang/luau), a fork of Lua created by Roblox, now an open source project.<br>
[Rokit](https://github.com/rojo-rbx/rokit): for managing my tools in my workspace.<br>
[Rojo](https://github.com/rojo-rbx/rojo): for facilitating connectivity with Roblox Studio environment and my code editor.<br>
[Luau-LSP](https://github.com/JohnnyMorganz/luau-lsp): for integrating the Luau language into my code editor.

# LLMs in this project
I will **not** use LLMs for the majority of this project.<br><br>
My main goal for this project is that to serve as a learning step rather than an established game. I want to demonstrate my ability to learn useful, modular code and not relying on an agent to do my work for me. Even if I learn through what the LLM outputs, I would prefer to practice proper habits of learning and learn how to **start** projects without the reliance of an agent.<br><br>
If I get stuck, I *may* resort to an LLM if I cannot find existing solutions already solved on the web. I will address my commits where I have used an LLM to help solve an issue.
